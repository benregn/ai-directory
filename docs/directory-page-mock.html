overview

Aeon is an open-source framework that runs unattended on GitHub Actions. It dispatches skills written in markdown and repairs the ones that fail, using your own agent keys.

The framework, including its workflows, 86 skills and a dashboard, is MIT licensed. A hosted Aeon Connect dashboard and MCP endpoint are available for free, and all runs happen on the user’s own GitHub Actions.

features

  • Runs unattended on your own GitHub Actions.
  • Dispatches skills defined in markdown.
  • Repairs skills that fail.
  • Ships with workflows, 86 skills and a dashboard.
  • Offers a free hosted Aeon Connect dashboard and MCP endpoint.
